# Provenance

This is an original, AI-assisted portfolio implementation created for siva-fy.
The code and synthetic fixtures were developed for this repository; no external
project was copied or rebranded. It is a learning/reference project, not a claim
of a production deployment, employer work, historical experience, or benchmark
performance. The README separates implemented behavior from future extensions.

Python and SQLite are used through the Python standard library. GitHub Actions
uses the official actions/checkout and actions/setup-python actions. Documentation
links are references for the underlying concepts, not sources of copied code.
